# PEI FACILE - MINISTERIAL CORPUS R01

Pacchetto di sorgenti ministeriali e asset runtime per PEI FACILE.

Contenuto principale:
- 4 modelli PEI ufficiali A1-A4 in PDF, pronti per `public/models/`;
- Allegato B Linee Guida, Allegato C e C1 e D.I. 153/2023;
- versioni DOCX editabili fornite come sorgenti di riferimento;
- estrazioni testuali/strutturate per ricerca e indicizzazione;
- manifest dei modelli con SHA-256;
- tassonomia per guida contestuale e futura libreria di frasi/casistiche.

IMPORTANTE:
I PDF/DOCX originali sono la fonte autorevole. Le estrazioni JSON/TXT sono solo ausili tecnici.
La libreria di frasi ricorrenti non deve confondere testi ministeriali con risposte precompilate.
