# CONTENT USAGE RULES

## Sorgenti ministeriali
Servono per:
- geometria/documentazione dei modelli;
- etichette e struttura dei campi;
- guida contestuale;
- regole dei diversi ordini scolastici;
- indicizzazione della libreria.

## Libreria frasi/casistiche
Le fonti ministeriali NON costituiscono da sole una raccolta di risposte pronte.
La libreria dovrà essere costruita separatamente con:
- esempi generici;
- contributi docenti;
- casistiche anonimizzate;
- tracciabilità della fonte;
- revisione umana.

Regola UI:
`SUGGERIMENTO -> DOCENTE SELEZIONA -> DOCENTE MODIFICA/CONFERMA -> APP INSERISCE`

Mai auto-compilare un PEI sulla sola base di una frase di libreria.
